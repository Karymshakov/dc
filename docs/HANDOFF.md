## Задача

Межвузовский хакатон INAI 2026, Бишкек. **ТЗ 5 «Бот поддержки на кыргызском
и русском».** Дедлайн последнего коммита — 21.11.2026, 09:00.

Telegram-бот определяет язык вопроса, находит ответ в базе FAQ учебного
оператора INAI Mobile и отвечает на том же языке.

Проверка жюри прогоняет функцию:

```python
answer(text) -> {"lang": "ky", "faq_id": 4, "confidence": 0.87, "candidates": [4, 1, 9]}
```

**Пороги зачёта:** верный `faq_id` первым в 75%, в топ-3 в 90%, язык в 90%,
плюс 3 из 5 диалогов с контекстом.

**Оценка (100 баллов):** автопроверка 40, качество кода 20, полнота
обязательных пунктов 20, бонусы 10, демо и ответы на вопросы 10.

## Чего НЕЛЬЗЯ менять

1. **Формат ответа `answer()`** — по нему считают 40 баллов:
   ровно `{"lang", "faq_id", "confidence", "candidates"}`.
2. **`answer()` не зависит от Telegram, сети и ключей.** Есть тест,
   блокирующий импорт `telegram` через `sys.meta_path`.
3. **`data/05_support/holdout.csv`** — открыт ровно один раз, дал 100%.
   Настраиваться по нему значит обесценить метрику.
4. **Числа ТЗ в `config.py`.**

## Ключевые решения (полностью в docs/DECISIONS.md)

- **Символьные n-граммы вместо токенного поиска.** Отрыв 12–14 пунктов
  на незнакомых вопросах. Причина в языке: кыргызский агглютинативный.
  Внешнее подтверждение: у кыргызских ASR-моделей WER 16,3% против
  CER 4,5% — пословная ошибка втрое выше посимвольной.
- **Слой синонимов — главный рычаг.** Без него 60% на tune, с ним 100%.
  Половина вопросов не имеет общих слов с базой: «Скока денег на счету?»
  против «Как проверить баланс?».
- **Ответ на ОДНОМ языке** — так требует ТЗ. Кнопка перерисовывает ту же
  карточку на другом языке. Двуязычен только `/start`.
- **Нажатие кнопки редактирует сообщение**, а не шлёт новое.
- **Сторож фактов вместо LLM для бонуса «без выдумки фактов».** Бот цитирует
  `faq.json`, но может выдать настоящий факт от чужой темы: код `*111#`
  реален, только он от доп. интернета, а не от баланса. Метод перенесён
  из работы авторов по AXON CRM: полнота 0,950 против 0,540 у
  NeMo Guardrails, 0,035 мс, без обращения к модели.
- **Gemini только для голоса и (опционально) переформулировки.** Текстовый
  поиск бесплатный. Ключ оплачивает человек, лимиты жёсткие.
- **`candidates` возвращаются и при отказе.** Измерено: без них top-3 на
  независимом наборе 84,1% — ниже порога 90%; с ними 97,7%.

## Дисциплина против подгонки — главное в процессе

`questions_dev.csv` размечен, и довести на нём 100% тривиально. Жюри
прогонит другие 40 формулировок.

1. Набор разделён на `tune` (25) и `holdout` (15).
2. **Эта защита дырявая, и мы это признаём:** состав `holdout` вычисляется
   вычитанием, оба файла в репозитории.
3. Поэтому главная проверка — **наборы, сочинённые с нуля**: три набора,
   124 вопроса, ни одного совпадения с размеченными данными. Сами файлы
   в репозиторий не попали, см. оговорку выше.
4. Тест падает, если синоним дословно повторяет размеченный вопрос.
   Он нашёл 10 таких случаев, они удалены.

**Правило команды:** утверждение «стало лучше» принимается только с цифрой
до и после. В `tune` 25 вопросов, один вопрос весит 4 процентных пункта,
поэтому прирост меньше двух пунктов — шум.

## Как запустить и проверить

```bash
python main.py ask "Как проверить баланс?"        # контракт жюри, без зависимостей
python main.py eval --split tune --errors         # точность с разбором ошибок
python -m faq_bot.ranking --errors                # сравнение двух методов
python -m pytest -q                               # 621 тест
python tools/check.py                             # всё сразу
python tools/run_bot.py                           # бот (гасит старые экземпляры)
```

Зависимостей для `answer()` нет. Для бота нужен `python-telegram-bot>=20`,
для тестов `pytest`.

> **В системе два Python.** `python` и `python3` — разные установки.
> Проверяйте ту, которой запускаете: `python -c "import telegram"`.

Настройки в `.env` (файл вне git): `TELEGRAM_BOT_TOKEN`, `GEMINI_API_KEY`,
`OPERATOR_CHAT_ID`, `REPHRASE_ENABLED`. Без любой решение работает,
отключается только соответствующая возможность.

## Риск, о котором нужно помнить

через терминал командой `python main.py ask`, она работает без сети.
