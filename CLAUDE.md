Решение на чистой стандартной библиотеке Python 3.10+. Сторонних зависимостей нет.
Дедлайн последнего коммита — 21.11.2026, 09:00.

## Запуск

```bash
python main.py                                              # result.json + map.html в out/
python main.py --expected data/07_coverage/expected.json    # то же плюс сверка с эталоном
python -m pytest -q                                         # тесты
```

## Правила работы в этом репозитории

**Правила расчёта лежат в `.claude/skills/rsrp-grid/SKILL.md`. Читай их перед
любой правкой в `src/rsrp_coverage/`.** Дословный источник — раздел 7 файла
`data/extracted/participants/CLARIFICATIONS_RU.md`.

1. **Числа спеки не меняются.** Пороги `-140`, `-44`, `-90`, `-105`, `500`, `1000`,
   `200`, `5`, `6371000` заданы заданием. Если расчёт не сходится с эталоном —
   виноват код, а не константа.
2. **После каждой правки расчётной логики** прогнать
   `python main.py --expected data/07_coverage/expected.json`.
   Вывод обязан содержать `СОВПАДАЕТ`. Коммит с расхождением не делать.
3. **Тесты проверяют правило, а не реализацию.** Тест, повторяющий текущий код,
   бесполезен. Не ослаблять проверку, чтобы тест позеленел.
4. **Расстояния только гаверсинусом.** Евклид по градусам не использовать нигде.
5. **Детерминированность.** Никаких зависимостей от порядка словарей, порядка
   чтения файлов и случайности. Все тай-брейки явные.
6. **Зависимости не добавлять.** Нулевой список зависимостей — страховка от
   «решение не запускается у жюри», а это ноль баллов за функциональность.
   `pytest` нужен только для разработки.
7. **Перед коммитом** вызывать агента `critic` (`.claude/agents/critic.md`).

## Состояние

Обязательная часть реализована, `result.json` совпадает с открытым эталоном
по всем четырём полям. Контрольные числа README сошлись: 4800 замеров после
очистки, 398 клеток с замерами, 387 учтённых.

**Все три бонуса сделаны:**

1. Сравнение жадного алгоритма с полным перебором. Жадный даёт C16+C17
   (108 клеток) против верного C09+C14 (111) — промахивается мимо эталона.
2. Тепловая карта: свой canvas-слой, оверлей в переключателе слоёв,
   по умолчанию выключен. Нормировка по фактическому диапазону медиан.
3. Сравнение покрытия днём и ночью: `src/rsrp_coverage/daynight.py`,
   вывод в `out/bonus_day_night.json`. Систематической разницы в данных нет,
   и отчёт говорит это прямо — см. [docs/DECISIONS.md](docs/DECISIONS.md), D-09.

Карта полностью автономна: Leaflet встроен в HTML из `vendor/leaflet`,
внешних скриптов и стилей на странице нет. Единственные внешние запросы —
плитки подложки, без которых карта остаётся читаемой.

Проверки: 115 тестов, совпадение с открытым эталоном, мутационный прогон
убивает 20 из 20.
