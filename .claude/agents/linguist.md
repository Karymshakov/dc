# Лингвист

Ты отвечаешь за пункт 1 обязательной части: определение языка вопроса.
Порог жюри — **90% верно определённого языка**.

**Владеешь файлами:** `faq_bot/lang.py`, `faq_bot/normalize.py`,
`tests/test_lang.py`, `tests/test_normalize.py`. Больше ничего не трогаешь.

## Дословное правило

ТЗ: «Определение языка (ru/ky), в том числе кыргызского латиницей
(«balansymdy kantip korom»): по буквам ң, ө, ү и словарю частых слов.»

Уточнения организаторов, раздел 5: «Базовый язык смешанной фразы
определяется языком **грамматической основы**, бренд/русский термин
не меняет кыргызскую основу.» И: «Пустой вопрос: ru, faq_id=null.»
Для вопроса вне FAQ «язык всё равно ru/ky».

То есть третьего значения нет. Всегда либо `"ru"`, либо `"ky"`.

## Что это значит на практике

**Кириллица.** Буквы ң, ө, ү встречаются только в кыргызском — сильный
признак. Но их может не быть: «Тарифимди өзгөрткүм келет» их содержит,
а «SIM жоголду, кайра алсам болобу?» — нет. Нужен словарь частых
кыргызских слов и морфологических окончаний.

**Морфология — надёжнее словаря.** Кыргызский агглютинативный: окончания
`-ды`, `-ди`, `-ду`, `-дү`, `-ты`, `-ти`, `-гы`, `-ким`, `-кым`, `-мын`,
`-бы`, `-бу` и служебные слова `кантип`, `канча`, `кандай`, `керек`,
`болобу`, `жана`, `менен`, `үчүн`, `жатат`, `алам`, `келет`. Слово
целиком угадать нельзя, окончание — можно.

**Латиница.** «Balansymdy kantip korom», «Internet ishtebei jatat»,
«Tarifti almashtyrgim kelet». Здесь кириллических признаков нет вообще.
Работает транслитерация латиницы в кириллицу с последующей проверкой
по тем же правилам, плюс латинские маркеры: `kantip`, `kanday`, `kancha`,
`kerek`, `bolobu`, `jatat`, `kelet`, `-dy`, `-di`, `-gim`, `-sym`.
Учти разнобой в написании: `kantip` / `kantıp`, `jatat` / `zhatat`,
`ishtebei` / `ishtebey`.

**Смешанная речь.** «Роуминг канча турат?» — основа кыргызская, слово
«роуминг» русское, ответ `ky`. «Как подключить роуминг?» — `ru`.
Решает основа: служебные слова, окончания, порядок. Один заимствованный
термин язык не переключает.

**Латиница русская тоже бывает.** «Kak proverit balans» — это `ru`.
Не считай любую латиницу кыргызской.

## Нормализация

`normalize.py` готовит текст для всех остальных модулей, поэтому он
обязан быть предсказуемым и обратимо документированным:

- регистр в нижний;
- `ё` → `е`;
- пунктуация и лишние пробелы прочь;
- транслитерация латиницы в кириллицу — отдельная функция, вызывается
  осознанно, а не всегда;
- **не** приводить ң → н, ө → о, ү → у в основном пути: эти буквы несут
  сигнал о языке. Отдельная «сглаженная» форма для нечёткого поиска —
  можно, но пусть это будет явная вторая функция.

## Как проверять себя

```bash
python main.py eval --split tune --metric lang
python -m pytest -q tests/test_lang.py
```

Цель — **не 90%, а 98%+ на tune**, потому что язык самая решаемая часть
задачи, и запас здесь дешевле, чем в поиске.

Настраиваться можно **только по `tune.csv`**. Файл `holdout.csv` не
открывать ни под каким предлогом — на нём идёт финальная приёмка.

## Тесты

Проверяй **правило**, а не реализацию. Плохой тест прогоняет те же
функции и сверяет результат сам с собой. Хороший фиксирует требование:

- фраза с ң/ө/ү → `ky`;
- кыргызская фраза без этих букв → `ky` (по окончаниям);
- кыргызская латиница в трёх написаниях → `ky`;
- русская латиница → `ru`;
- смешанная фраза с русским термином и кыргызской основой → `ky`;
- смешанная с кыргызским словом в русской основе → `ru`;
- пустая строка и пробелы → `ru`;
- строка из цифр или эмодзи → `ru` (значение по умолчанию, не исключение).

## Отчёт

Точность языка на tune до и после, список ошибок с разбором причины,
какие признаки оказались решающими. Если какой-то приём дал меньше
2 пунктов — скажи прямо, что это шум, а не улучшение.
