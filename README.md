# Карта покрытия района Бишкека

ТЗ № 7 осеннего хакатона INAI 2026. Проект строит карту по синтетическим замерам RSRP и подбирает две площадки для новых базовых станций.

## Запуск

Для запуска из корня репозитория достаточно одной команды. Требуется Python 3.10 или новее.

```bash
python main.py
```

Сторонние пакеты Python не требуются. Пути можно задать явно.

```bash
python main.py --data-dir data --out-dir .
```

Если в Windows команда `python --version` открывает Microsoft Store, укажите путь к установленному Python или воспользуйтесь `uv`, если Python 3.14 уже установлен через него.

```powershell
uv run --offline --no-cache --python 3.14 python main.py
```

Откройте полученный `map.html` в браузере. Подложка, слои и данные встроены в один HTML-файл и работают офлайн. Начните с трёх вопросов:

1. Где сигнал слабый? На экране «Сигнал» щёлкните по клетке, чтобы увидеть медиану замеров и их количество.
2. Какие две площадки дают максимальный охват по ТЗ? Откройте «Выбор пары». Здесь охват считается по расстоянию от площадки до центра слабой клетки.
3. Есть ли здание на пути от площадки? Откройте карточку слабой клетки и нажмите «Проверить здания на пути». Профиль показывает линию до той же клетки при выбранной высоте антенны.

## Данные

| Файл | Содержимое |
| --- | --- |
| `measurements.csv` | Замеры `lat`, `lon`, `rsrp_dbm`, `timestamp` |
| `towers.csv` | Действующие базовые станции `id`, `lat`, `lon` |
| `candidates.csv` | Площадки-кандидаты `id`, `lat`, `lon` |
| `bounds.json` | Границы района, начало сетки, сторона клетки, радиус Земли и часовой пояс |

Для жюри команда формирует `result.json` по всем замерам. В нём `worst_cells` содержит до трёх объектов с полями `cell_id` и `rsrp_median`, `best_candidates` содержит два ID, `dropped_rows` считает отброшенные строки, а `covered_weak_cells` — уникальные слабые клетки в радиусах точной пары. Открытый эталон хранится в `data/expected.json`.

Подложка района содержит реальные улицы и другие объекты OpenStreetMap. Источник — векторные тайлы OpenFreeMap в схеме OpenMapTiles, уровень 14, сборка `20261115_080022_pt` от 15 ноября 2026 года. Замеры, базовые станции и площадки синтетические. [Происхождение подложки и лицензия](web/bishkek-source.md)

Настройки слоёв и периода находятся в меню «Дополнительно». Для онлайн-подложки 2ГИС нужен ключ [Raster Tiles API](https://docs.2gis.com/maps/others/rastertiles/overview), который действует в текущей вкладке до её обновления. При ошибке загрузки карта возвращается к офлайн-подложке. Профиль застройки использует контуры и высоты OpenStreetMap.

## Расчёт

1. Проверяем координаты по включённым границам района, RSRP от −140 до −44 дБм включительно и дату со временем в ISO 8601. Время без смещения считаем местным. Для поиска дублей приводим числа к одному формату и время к UTC, затем сравниваем все четыре поля.
2. Раскладываем замеры по локальной сетке 200 × 200 м и считаем медианы для клеток с пятью и более замерами. Цвет зависит от медианы RSRP. Зелёный соответствует RSRP ≥ −90 дБм, жёлтый — −105 ≤ RSRP < −90 дБм, красный — RSRP < −105 дБм. Для трёх худших клеток берём первые три позиции после сортировки по медиане и ID.
3. Проверяем расстояния по формуле гаверсинуса. Площадка допустима при расстоянии ≥ 500 м до каждой действующей станции. Она покрывает слабую клетку, если до центра клетки ≤ 1 км.
4. Перебираем пары допустимых площадок и сравниваем размер объединения их покрытий. Для 20 кандидатов существует максимум 190 пар, так что полный перебор даёт точный максимум за небольшое число операций. При равном охвате побеждает лексикографически первая пара ID.

## Режимы карты

| Режим | Что показывает |
| --- | --- |
| Отказ станции | Штатный охват пары и клетки, которые остаются в охвате при отказе одной площадки |
| Сигнал | Медианы RSRP по клеткам и тепловой слой плотности слабых клеток |
| Полный перебор | Клетки в радиусах пары, выбранной полным перебором, и остаток слабых клеток |
| Жадная пара | Клетки, доступные паре, выбранной жадным алгоритмом, и остаток слабых клеток |
| Выбор пары | Клетки, которые покрывают обе пары, только одна из пар или ни одна |
| Своя пара | Ручной выбор площадок и подбор лучшей пары с заданными ограничениями |
| Застройка | Профиль прямой от антенны до центра слабой клетки с контурами пересечённых зданий |

В сценарии «Отказ станции» `A` и `B` — множества слабых клеток в радиусе каждой площадки. При работе обеих охват равен размеру объединения `A ∪ B`. При отказе одной площадки остаётся охват второй, поэтому худший из двух сценариев равен `min(|A|, |B|)`.

Список показывает недоминируемые пары. Вариант исключается, если у другой пары оба показателя не ниже и хотя бы один выше. При равенстве обоих показателей остаётся лексикографически первая пара ID. Список обновляется для выбранных периода и радиуса. После отказа кнопка «Подобрать замену» сохраняет работающую площадку и исключает отказавшую.

На экране «Выбор пары» видно, сколько слабых клеток охватывает каждый алгоритм. Нажатие на группу под картой включает или приглушает её. Круги радиусом 1 км можно включить в меню «Дополнительно».

Блок «Приоритет самых слабых клеток» сравнивает варианты при пороге −110, −115 или −120 дБм. Алгоритм максимизирует число клеток с медианой на пороге или ниже, при равенстве выбирает больший общий охват слабых клеток, затем первую пару по ID. При −115 дБм `C16 + C17` покрывает 13 из 13 критических клеток, базовая `C09 + C14` — 9 из 13. Их общий охват составляет 108 и 111 слабых клеток соответственно. Кнопка «Показать на карте» открывает различия при радиусе 1 км.

В режиме «Своя пара» выберите слот, затем щёлкните по допустимой точке на карте или выберите её из списка. В списке «Недоступна» можно указать любую допустимую площадку. Кнопка «Подобрать пару» ищет лучший вариант для выбранных периода и радиуса с учётом закреплённой площадки и ограничения. Переключатель «Сравнить с базой» показывает, какие клетки вошли в охват и какие вышли из него относительно базовой пары.

В сценариях «Отказ станции» и «Своя пара» ползунок «Радиус в модели» меняет порог охвата от 800 до 1200 м с шагом 100 м. Карта сопоставляет лучшую пару для сценария с базовой парой из `result.json` при одном радиусе и за один период. На открытом наборе базовая пара — `C09 + C14`. Для `result.json` используется радиус 1000 м по ТЗ. Допуск в 500 м до действующих станций действует при любом радиусе.

В блоке «Выбор при неопределённом радиусе» можно выбрать одну пару сразу на несколько сценариев. Для каждого радиуса берём разницу между охватом лидера этого сценария и охватом проверяемой пары. Побеждает пара с наименьшим максимальным отставанием. При равенстве сравниваем сумму отставаний, затем ID. Для диапазона 800–1000 м `C16 + C17` даёт до трёх клеток отставания, а базовая `C09 + C14` — до пяти. В таблице можно открыть любой из сценариев на карте.

«Скачать сценарий» сохраняет локальный JSON для выбранной пары. В нём есть период, радиус, координаты площадок и ID клеток, которые остались в охвате, добавились или выпали. В стресс-тесте изменения считаются относительно работы обеих площадок той же пары, в режиме «Своя пара» — относительно базовой пары при выбранном радиусе и периоде.

Переключатель периода показывает медианы, худшие клетки и охват отдельно днём (06:00–18:00) и ночью (18:00–06:00) по времени Бишкека. Границы интервалов включены слева. Полный перебор и жадный алгоритм выбирают площадки по всем замерам. При смене периода карта оценивает эти пары на клетках выбранного периода. В `result.json` входят результаты по всем замерам.

Тепловой слой сглаживает плотность центров клеток с медианой ниже −105 дБм. У каждого такого центра одинаковый вес. Медиану RSRP можно посмотреть в карточке клетки.

## Проверка застройки

Откройте «Дополнительно» → «Застройка» или перейдите из карточки слабой клетки. При переходе карта выбирает ближайшую площадку из просмотренной пары в пределах 1 км, если такая есть, иначе ближайшую из допустимых. В «Настроить трассу» можно сменить площадку или клетку. При смене площадки выбранная клетка сохраняется. Профиль показывает отдельно медиану входных замеров и геометрию от антенны до приёмника высотой 1,5 м в центре клетки. Для расчёта используем интервалы пересечения с контурами, учитываем внутренние дворы и сравниваем высоту линии с нижней отметкой и крышей каждого здания.

В вырезке OpenStreetMap 11 800 зданий. У 9 высота указана в метрах, для 3 404 она оценена по этажности из расчёта 3 м на этаж, для остальных высота неизвестна. Пересечённые контуры без высоты выделены пунктиром и посчитаны отдельно. [Источник, подготовка вырезки и лицензия](web/bishkek-source.md)

В «Дополнительно → Застройка» карта отдельно показывает медиану исходных замеров в дБм и расчётные потери на трассе в дБ. Python строит профиль земли GEDTM30, пересекает линию с контурами OSM и рассчитывает дифракционные потери по Bullington. Разность двух расчётов, на рельефе с крышами и на одном рельефе, даёт вклад известных крыш. «Настроить трассу» меняет площадку, клетку, высоту антенны от 5 до 80 м с шагом 5 м и частоту модели 900, 1 800 или 2 600 МГц. Приёмник на высоте 1,5 м в центре клетки. [ITU-R P.526-16, § 4.5.1](https://www.itu.int/rec/R-REC-P.526-16-202511-I/en)

Пример `C15 → X011_Y015` при 1 800 МГц. На 25 м крыши добавляют 37,1 дБ, на 40 м — 10,2 дБ. На 40 м прямая проходит выше крыш, но зазор ещё влияет на дифракцию. Входная медиана −107,1 дБм по 11 замерам сохраняется. Для оценки будущего RSRP потребуются мощность, параметры и направление антенн, полный расчёт распространения и полевая калибровка. Для трасс с концом внутри контура цифра скрыта, а при неизвестных высотах между концами карта помечает её как частичную.

Пункт «Меняют ли здания выбор пары?» сравнивает варианты с заменой одной площадки. Сравнение идёт на одних и тех же слабых клетках в радиусе обеих пар. Клетка входит в выборку, когда у всех площадок двух пар в пределах 1 км есть расчёт по известным или оценённым высотам. Для каждой пары берём меньшие потери, а 10 дБ используем как условный лимит дифракции. Python считает число клеток в лимите на одном рельефе и после добавления крыш.

В открытом наборе при 25 м и 1 800 МГц для `C15 + C19` и `C10 + C15` пригодны 8 из 66 общих клеток. Без крыш обе пары дают 8 из 8. С крышами первая даёт 2, вторая 3. На карте видна решающая клетка `X009_Y001`: для C19 потери растут с 0 до 45,6 дБ, для C10 остаются 0 дБ. Общая площадка C15 дальше 1 км от этой клетки. Для официальной пары оценено 0 из 111 клеток по этому строгому критерию. Эффект показан на общих проверенных клетках. Официальный ответ формируется по геометрии и записывается в `result.json`.

Кнопка «Где не хватает данных» раскрашивает эти 111 клеток по первой трассе, которую стоит проверить. У 51 клетки на таком пути не хватает высот, у 49 исходная точка попадает в контур здания, у 9 в контур попадает центр клетки, у 2 точки совпадают. Если есть две трассы в 1 км, список клетки показывает обе причины. Точка C14 из CSV лежит в контуре больницы OSM `88392617`. На ней нужно уточнить фактическое положение антенны и отметку крыши. Для C09 → X004_Y008 уже известны три контура, где нужны высоты. Для сравнения C09 + C14 и C10 + C15 следует заранее зафиксировать общий набор клеток и одинаковые параметры модели. [Контур C14 в OpenStreetMap](https://www.openstreetmap.org/way/88392617)

«Сравнение по 2ГИС» показывает клетки X012_Y013 и X010_Y015. Точка C14 остаётся на координатах из CSV, 42,862483° с. ш. и 74,595568° в. д. В сценарии антенна находится над крышей больницы. Две пары сравниваются при одинаковых 25 м над местной землёй и 1 800 МГц. В 1 км от центра каждой клетки только C14 в первой паре и C15 во второй. На X012_Y013 потери дифракции C14 после добавления крыш растут с 0 до 39,9 дБ, C15 остаются 0 дБ. При условном лимите 10 дБ на этой клетке проходит C10 + C15 во всех проверенных вариантах.

Этажность проверена вручную по карточкам 2ГИС и записана со ссылками в `web/roof-study.json`. При 3 м на этаж высота крыши под C14 оценивается в 6 м, а четыре ранее неизвестных здания — в 3, 6, 6 и 6 м. У здания 546 на этой трассе пять этажей по 2ГИС и четыре по OSM. Принимаем пять в основном расчёте, оба значения проверяем в шести сценариях с 2,5, 3 и 4,5 м на этаж. При 25 м получаем 35,3–44,6 дБ для C14. Высоты крыш и высота установки требуют обследования. Исходная модель и ответ ТЗ используют исходные данные.

На X010_Y015 при тех же настройках у C14 получилось 38,4 дБ, у C15 — 0 дБ по основной оценке. В 24 сценариях C14 даёт 35,3–43,8 дБ, C15 — 0–43,4 дБ. У дома 149 по Боконбаева 2ГИС указывает 5 этажей, исходный объект OSM — 9. Также проверены два варианта края корпуса на Исанова, 1 и два значения высоты пристройки к дому 146. При 25 м прохождение лимита для C15 зависит от этих оценок. [Карточка дома 149 в 2ГИС](https://2gis.kg/bishkek/geo/15763234351062479) · [Объект 37081078 в OSM](https://www.openstreetmap.org/way/37081078)

## Демо за три минуты

1. **0:00–1:02. Район и слабый сигнал.** Откройте худшую клетку на экране «Сигнал». Объясните сетку 200 × 200 м, медиану −124,5 дБм и 200 строк, отброшенных при очистке.
2. **1:02–2:19. Два критерия выбора.** На экране «Выбор пары» покажите `C09 + C14` и её 111 слабых клеток. Откройте «Приоритет самых слабых клеток» при −115 дБм и покажите, как `C16 + C17` добавляет четыре критические клетки ценой трёх клеток общего охвата.
3. **2:19–3:00. Результат для жюри.** Покажите `result.json` и объясните выбор между 111 клетками общего охвата и 13 из 13 критических клеток. На вопрос про здания откройте «Дополнительно» → «Застройка» → «Меняют ли здания выбор пары?». Покажите клетку X009_Y001 и назовите объём проверенной выборки.

## Вопросы на защите

**Почему 105 лучше 111 в стресс-тесте?** Зависит от критерия. `C09 + C14` даёт максимальный штатный охват в 111 клеток. Если приоритет — охват при отказе любой одной площадки, у `C09 + C16` в худшем сценарии остаётся 61 клетка против 52 у штатного лидера. Её штатный охват составляет 105 клеток.

**Почему жадная пара выигрывает днём, а в итоговом JSON другая пара?** Для итоговой оценки берём все замеры. Переключение на день меняет медианы и набор слабых клеток, а выбранные по всем замерам площадки остаются фиксированными. Так видно, как те же варианты работают при разном составе измерений.

**Почему клетка с пятью замерами весит столько же, сколько клетка с двадцатью?** По ТЗ цель — число слабых клеток. Пять валидных замеров дают клетке право войти в расчёт, медиана определяет класс сигнала, а вклад каждой слабой клетки равен единице.

**Что происходит ровно на 500 м и 1 км?** Площадка допустима, если от неё не меньше 500 м до каждой действующей станции. При расстоянии до центра слабой клетки не больше 1 км она входит в охват. Клетка в двух радиусах считается один раз.

**Почему полный перебор уместен и что делать при равенстве?** В открытом наборе допущены 16 из 20 площадок, поэтому проверяем 120 пар. Сравниваем размеры объединений покрытых клеток. Если охват одинаков, выбираем лексикографически первую пару ID.

**Почему для диапазона выбрана другая пара?** В ТЗ оценивают только радиус 1 км. Для диапазона сравниваем одну и ту же пару с лидером при каждом радиусе. Например, при 800 м `C16 + C17` охватывает 80 клеток, на 5 больше базовой пары. При 1000 м она охватывает 108 клеток, уступая базовой три.

**Почему крыша ниже прямой всё ещё даёт потери?** Для малого зазора препятствие заходит в зону Френеля. Дифракционная оценка зависит от зазора, положения крыши на трассе и длины волны. Для проверки межсотовых помех дополнительно нужны параметры соседних секторов и данные SINR. [ITU-R P.526 о дифракции](https://www.itu.int/rec/R-REC-P.526-16-202511-I/en)

Python рассчитывает профили и сравнение пар во время сборки. Для открытия HTML достаточно браузера.

Открытый набор совпадает с эталоном по всем полям. После очистки остаётся 4800 замеров. В расчёт покрытия входят 387 клеток с пятью и более замерами. Пара `C09` и `C14` покрывает 111 слабых клеток, жадный выбор `C16` и `C17` покрывает 108. При очистке отбрасывается 200 строк. Скрытый набор проверяет жюри.

Для карты используются Leaflet 1.9.4 и Leaflet.heat 0.2.0. Тексты лицензий включены в HTML и лежат рядом с библиотеками. [Leaflet](web/vendor/leaflet.LICENSE), [Leaflet.heat](web/vendor/leaflet-heat.LICENSE).
